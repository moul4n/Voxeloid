Offline copies of the design documents. Also published as Claude artifacts, where
they are kept up to date; these are snapshots. Open any of them in a browser.

  voxeloid-design.html       THE GAME. Premise, three acts, the eat-or-seal loop,
                             stacking and merging layers, the critical-mass cost
                             curve with checked numbers, heat, elements, scale,
                             what travels between worlds, open questions.

  vox-speed-bible.html       The technical bible: pillars, frame budgets, density
                             tiers, the art pipeline and art direction, the core
                             systems, project settings.

  phase0-build-plan.html     How to build the stress bed: ten steps with done
                             criteria, swarm shader design, the metrics recorder
                             spec, the benchmark protocol, day-one checklist.

  stacking-and-scaling.html  Research into how other games stack multipliers, the
                             five-layer blending model, the reaction table, the
                             buildsim findings, and a mechanic idea generator.

  voxeloid-particles.html    THE PARTICLE ARCHITECTURE. Why 100k+ particles is a
                             collision problem to delete rather than optimise: the
                             field/flight/surface-flow model, a live prototype you
                             can run in a browser, measured scaling, material
                             settings, and the Godot renderer capability table.
                             Read this before touching swarm.gd.

  voxeloid-prior-art.html    Prior art survey (searched 20 Sept 2026). 30+ games
                             checked, three near neighbours, a side-by-side of what
                             each playfield looks like, and a watchlist. Re-check
                             before any public announcement — prior art rots.

Read voxeloid-design.html first. The other three predate it in places — the bible
still describes a downward-gravity 2D game rather than the radial cross-section,
and the phase 0 plan's scenarios don't yet model accretion or camera zoom. The
"What this changes in the build" section of the design doc lists every known gap.
