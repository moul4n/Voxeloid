Sequence

Build order

Each step has a "done when" that's observable, and the recorder comes second, before any rendering work, so every rendering step is measured from its first commit.

Rendering

Swarm renderer design

The swarm is where 10,000 to 50,000 things live, so it gets exactly one draw call per atlas and no per-object nodes. The CPU's only job is to write a slot when something spawns.

Per-instance data

WhereFieldMeaning
transformoriginSpawn position. Never updated after spawn on the GPU path.
colorrgbaTint from the strongest buff; alpha unused (fade is computed).
custom.rt0Spawn time in seconds (Time.get_ticks_msec()/1000, same clock as the shader's TIME uniform we pass in).
custom.gvxInitial velocity x, pixels/s.
custom.bvyInitial velocity y, pixels/s.
custom.aseed · framePacked: 8-bit atlas frame index + 8-bit lifetime tenths + 16-bit seed for wobble phase.

Vertex shader sketch

shader_type canvas_item;

uniform float now;            // set from script each frame
uniform float gravity = 900.0;
uniform float floor_y = 520.0;
uniform int   layer_mask = 0; // bit 0 tint · 1 glow · 2 pulse · 3 wobble · 4 trail · 5 emit
uniform vec4  glow_col : source_color = vec4(1.0, 0.63, 0.29, 1.0);

varying float v_age01;
varying flat int v_frame;

void vertex() {
    vec4 d = INSTANCE_CUSTOM;
    float t  = max(now - d.r, 0.0);
    float packed = d.a;
    int   frame  = int(mod(packed, 256.0));
    float life   = floor(mod(packed / 256.0, 256.0)) * 0.1;
    float seed   = floor(packed / 65536.0) / 65535.0;

    float age01 = clamp(t / max(life, 0.01), 0.0, 1.0);
    v_age01 = age01; v_frame = frame;

    // ballistic with one cheap floor bounce
    vec2 p = vec2(d.g * t, d.b * t + 0.5 * gravity * t * t);
    float local_floor = floor_y - (MODEL_MATRIX * vec4(0,0,0,1)).y;
    if (p.y > local_floor) { p.y = local_floor - (p.y - local_floor) * 0.35; }

    float s = 1.0;
    if ((layer_mask & 4) != 0) s += 0.15 * sin(now * 9.0 + seed * 6.283);
    if ((layer_mask & 8) != 0) VERTEX.x += 1.5 * sin(now * 14.0 + seed * 6.283 + VERTEX.y * 0.3);
    VERTEX = VERTEX * s + p;
    if (age01 >= 1.0) VERTEX = vec2(1e6); // dead: push off-screen, slot free
}

void fragment() {
    // atlas frame lookup from v_frame, then:
    vec4 c = texture(TEXTURE, UV);
    if ((layer_mask & 1) != 0) c.rgb *= COLOR.rgb;
    if ((layer_mask & 2) != 0) c.rgb += glow_col.rgb * 0.35 * step(0.5, c.a);
    c.a *= 1.0 - smoothstep(0.7, 1.0, v_age01);
    COLOR = c;
}

Dead instances are pushed far off-screen rather than rebuilt, so the buffer never shrinks; a free-list on the CPU side hands out slots. Spawning 10,000 in one frame is 10,000 set_instance_custom_data calls, which is why the spike scenario exists: if that hurts, batch-write via MultiMesh.buffer as one PackedFloat32Array instead.

Watch the clock. The shader's built-in TIME and the script's tick clock drift apart. Pass now as a uniform every frame from the same source used to stamp t0. This is the bug that makes swarms jitter and it's invisible at low counts.

Recorder

Metrics recorder spec

Compact by design: one summary you can paste into a chat, plus the raw frame times for when the summary says something surprising. Every run is self-describing, so a folder from three months ago still means something.

Behaviour

  • Preallocated PackedFloat32Array of 6,000 frames (10 s at up to 600 fps). Recording never allocates.
  • Captures per frame: total frame time, process time, physics time, and Godot's RenderingServer.get_rendering_info() counters (draw calls, primitives) sampled once per second, not per frame.
  • Warm-up frames are recorded but excluded from stats (warmup_s in the summary says how many).
  • Writes on stop, never during; output is user://bench/<date>_<time>_<scenario>_<githash>/.
  • Optional --bench=late --seed=7 --quit command-line args so a run can be scripted from a terminal with no keypresses.

Core of metrics.gd

extends Node
## Autoload "Metrics". Ring buffer of frame times; writes CSV + JSON on stop.

const CAP := 6000
var _frame := PackedFloat32Array()
var _proc  := PackedFloat32Array()
var _phys  := PackedFloat32Array()
var _live  := PackedInt32Array()
var _n := 0
var recording := false
var meta := {}          # filled by the scenario runner before start()

func _ready() -> void:
    _frame.resize(CAP); _proc.resize(CAP); _phys.resize(CAP); _live.resize(CAP)

func start(scenario: String, extra: Dictionary) -> void:
    _n = 0
    meta = extra.duplicate()
    meta["scenario"] = scenario
    meta["git"] = _git_hash()
    meta["godot"] = Engine.get_version_info().string
    meta["renderer"] = ProjectSettings.get_setting("rendering/renderer/rendering_method")
    meta["gpu"] = RenderingServer.get_video_adapter_name()
    meta["cpu"] = OS.get_processor_name()
    recording = true

func _process(_dt: float) -> void:
    if not recording or _n >= CAP: return
    _frame[_n] = Performance.get_monitor(Performance.TIME_PROCESS) * 1000.0 \
               + Performance.get_monitor(Performance.TIME_PHYSICS_PROCESS) * 1000.0
    _proc[_n]  = Performance.get_monitor(Performance.TIME_PROCESS) * 1000.0
    _phys[_n]  = Performance.get_monitor(Performance.TIME_PHYSICS_PROCESS) * 1000.0
    _live[_n]  = meta.get("live_swarm_now", 0)
    _n += 1

func stop() -> Dictionary:
    recording = false
    var skip := int(meta.get("warmup_s", 3.0) * (_n / meta.get("capture_total_s", 13.0)))
    var s := _stats(_frame, skip)
    var out := meta.duplicate()
    out["frames"] = _n - skip
    out["frame_ms"] = s
    out["process_ms"] = _stats(_proc, skip)
    out["physics_ms"] = _stats(_phys, skip)
    out["pass"] = s["p99"] <= meta.get("pass_p99_ms", 3.33)
    _write(out)
    return out

func _stats(a: PackedFloat32Array, skip: int) -> Dictionary:
    var v := a.slice(skip, _n); v.sort()
    var n := v.size()
    var sum := 0.0
    for x in v: sum += x
    var low := v.slice(int(n * 0.99), n)   # worst 1% frames → 1% low fps
    var lsum := 0.0
    for x in low: lsum += x
    return {
        "avg": sum / n, "p50": v[n / 2], "p95": v[int(n * 0.95)],
        "p99": v[int(n * 0.99)], "max": v[n - 1],
        "low1pct_fps": 1000.0 / (lsum / max(low.size(), 1))
    }

_write() makes the run folder, dumps JSON.stringify(out, " ") and streams the CSV with a FileAccess. _git_hash() reads .git/HEAD and the ref it points at; if there's no repo it returns "nogit" and the overlay turns the hash red so you notice.

Procedure

Benchmark protocol

The point of the protocol is that two runs a month apart are comparable. Anything that changes between runs must be in the summary; anything that isn't in the summary must be held constant.

  1. Close browsers and anything with a GPU overlay. Plug in the laptop if it is one. Wait for the machine to idle.
  2. Window at exactly 2× (1920×1080), not fullscreen borderless, not maximised. Same monitor each time.
  3. Commit first. The hash in the summary must point at the code that ran.
  4. Press F5 (full suite) or F6 (current scenario only). Do not touch the mouse during capture.
  5. Each scenario: 3 s warm-up, 10 s capture, 1 s cool-down. Suite is about 75 s.
  6. Run the suite three times. Keep the median late p99 as the number for that commit. If the three disagree by more than 8%, something is running in the background; start again.
  7. Give the run a label with L before starting (e.g. gpu-path, trail-ghosts) so folders read like a changelog.
  8. Copy the late summary line into BENCH.md in the repo: date, hash, label, p99, pass. One line per commit tested. That file is the project's performance history.

Reference runs. The first passing late run gets its whole folder committed under bench/reference/. compare.py uses it as the default baseline, so from then on any run answers "better or worse than the day it first passed?"

Tooling

Dev PC

Day-one checklist

In this order. The first three take twenty minutes and mean every later number is trustworthy.

  • Install Godot 4.4+ standard build (not .NET, unless the C# fallback becomes necessary). Note the exact version.
  • Install Blender 4.x and the MagicaVoxel importer add-on for the bake script. Confirm blender --background --python art/bake/bake.py runs.
  • Install MagicaVoxel. Set the default palette to the 32-colour ramp and save it in art/vox/palette.png.
  • Python 3 on PATH for compare.py. No packages needed.
  • Git repo created, first commit is the empty project with settings locked. Add user://bench to nothing — it lives outside the repo by design.
  • Record the machine: GPU, driver version, CPU, RAM, monitor refresh, in BENCH.md header.
  • Set the monitor to its max refresh rate and confirm Godot reports it. V-Sync off in the project and in the GPU driver panel for the Godot executable.
  • Build steps 1–3 (skeleton, recorder, overlay) and get the empty-scene run into BENCH.md as row one.
